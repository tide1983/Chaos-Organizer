# Chaos Organizer

Мессенджер с ботом-органайзером, созданный в рамках дипломной работы курса «Продвинутый JavaScript в браузере».

- **Статус сборки AppVeyor**: ![AppVeyor](https://ci.appveyor.com/api/projects/status/ваш-статус?svg=true)

## 📋 Реализованные функции

### Обязательные
1. **Сохранение истории** — все текстовые сообщения и ссылки сохраняются в памяти сервера.
2. **Кликабельные ссылки** — ссылки вида `http://` и `https://` автоматически становятся кликабельными.
3. **Загрузка файлов** — поддержка Drag & Drop и иконки загрузки. Сохраняются изображения, видео, аудио и другие файлы.
4. **Скачивание файлов** — каждый загруженный файл можно скачать по ссылке.
5. **Ленивая подгрузка** — сначала загружаются последние 10 сообщений, при прокрутке вверх подгружаются следующие 10.

### Дополнительные (реализовано 5 из списка)
1. **Синхронизация** — при открытии приложения в нескольких вкладках контент синхронизируется через WebSocket.
2. **Поиск по сообщениям** — интерфейс в шапке чата + серверная фильтрация.
3. **Команды бота** — минимум 5 команд (`@chaos: погода`, `@chaos: время`, `@chaos: шутка`, `@chaos: помощь`, `@chaos: курс`).
4. **Закрепление сообщений** — можно закрепить одно сообщение, оно отображается вверху чата.
5. **Избранное** — добавление сообщений в избранное и просмотр списка.
6. **Просмотр вложений по категориям** — модальное окно с группировкой файлов на изображения, видео и другие.

*(Примечание: пункты 5 и 6 можно объединить в один, если считать, что избранное и вложения — это две разные функции. По заданию нужно минимум 5, у нас 6).*

## 🛠 Технологии
- **Frontend**: Vanilla JS, Webpack, Babel, ESLint.
- **Backend**: Koa, WebSocket (ws), koa-body, koa-static, koa-mount.
- **CI/CD**: AppVeyor, Heroku.
