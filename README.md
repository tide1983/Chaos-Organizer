# Chaos Organizer

Мессенджер с ботом-органайзером, созданный в рамках дипломной работы курса «Продвинутый JavaScript в браузере».

- **Статус сборки AppVeyor**: [![Build status](https://ci.appveyor.com/api/projects/status/1y9fhj9bs64tckvk/branch/main?svg=true)](https://ci.appveyor.com/project/tide1983/chaos-organizer)

## 📋 Реализованные функции

В проекте реализованы все обязательные функции и 6 дополнительных (требовалось минимум 5).

1. **Сохранение истории** — все текстовые сообщения и ссылки сохраняются в памяти сервера.
2. **Кликабельные ссылки** — ссылки вида `http://` и `https://` автоматически становятся кликабельными.
3. **Загрузка файлов** — поддержка Drag & Drop и иконки загрузки. Сохраняются изображения, видео, аудио и другие файлы.
4. **Скачивание файлов** — каждый загруженный файл можно скачать по ссылке.
5. **Ленивая подгрузка** — сначала загружаются последние 10 сообщений, при прокрутке вверх подгружаются следующие 10.
6. **Синхронизация** — при открытии приложения в нескольких вкладках контент синхронизируется через WebSocket.
7. **Поиск по сообщениям** — интерфейс в шапке чата + серверная фильтрация.
8. **Команды бота** — минимум 5 команд (`@chaos: погода`, `@chaos: время`, `@chaos: шутка`, `@chaos: помощь`, `@chaos: курс`).
9. **Закрепление сообщений** — можно закрепить одно сообщение, оно отображается вверху чата.
10. **Избранное** — добавление сообщений в избранное и просмотр списка.
11. **Просмотр вложений по категориям** — модальное окно с группировкой файлов на изображения, видео и другие.

## 🛠 Технологии
- **Frontend**: Vanilla JS, Webpack, Babel, ESLint.
- **Backend**: Koa, WebSocket (ws), koa-body, koa-static, koa-mount.
- **CI/CD**: AppVeyor, Render.

## 📦 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/tide1983/Chaos-Organizer.git
   cd Chaos-Organizer

2. Установите зависимости: npm install
3. Соберите фронтенд: npm run build
4. Запустите сервер: npm start
5. Откройте http://localhost:3000 в браузере.

## 📝 Как пользоваться:
Отправка сообщения: введите текст в поле внизу и нажмите Enter или кнопку «Отправить».
Загрузка файла: перетащите файл в окно чата или используйте Drag & Drop.
Поиск: введите запрос в поле поиска в шапке.
Бот: отправьте @chaos: помощь, чтобы увидеть список команд.
Закрепление: наведите на сообщение и нажмите 📌.
Избранное: наведите на сообщение и нажмите ⭐. Список избранного — кнопка ⭐ в шапке.
Вложения: кнопка 📎 в шапке открывает список всех загруженных файлов по категориям.
